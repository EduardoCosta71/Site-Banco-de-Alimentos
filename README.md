# Banco de Alimentos

## Sobre o projeto

O Banco de Alimentos é um projeto de desenvolvimento web que apresenta uma organização fictícia dedicada ao combate à fome, à distribuição de alimentos e ao apoio de famílias em situação de vulnerabilidade social.

A aplicação foi desenvolvida com foco na apresentação institucional, organização das informações e experiência de navegação, incentivando a participação da comunidade por meio de doações e voluntariado.

## Objetivo

Desenvolver um site institucional com múltiplas páginas independentes, navegação intuitiva e funcionalidades interativas, aplicando conceitos fundamentais de desenvolvimento front-end.

## Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** implementação de interações e funcionalidades dinâmicas.

## Estrutura do site

O projeto é composto pelas seguintes páginas:

- **Início:** apresentação da organização e suas principais iniciativas.
- **A ONG:** informações institucionais e atuação social.
- **Projetos:** apresentação dos projetos e iniciativas da organização.
- **Doações:** informações e formulários para contribuições.
- **Voluntariado:** apresentação das oportunidades de participação.
- **Notícias:** divulgação de informações e conteúdos relacionados.
- **Galeria:** exposição de imagens.
- **Contato:** informações e formulário de comunicação.
- **Entrar:** página de acesso.

## Funcionalidades

- Navegação entre páginas independentes.
- Filtros de projetos por categoria.
- Formulários com validações e interações em JavaScript.
- Elementos interativos para melhorar a experiência do usuário.
- Layout responsivo para diferentes tamanhos de tela.

## Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto.
3. Abra o projeto no Visual Studio Code.
4. Execute o arquivo `index.html` utilizando o navegador ou a extensão Live Server.
