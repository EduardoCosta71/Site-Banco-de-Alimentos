## TEMA
Desenvolvimento de um site institucional para um Banco de Alimentos, organização fictícia voltada ao combate à fome, à distribuição de alimentos e ao apoio de famílias em situação de vulnerabilidade social. 

## OBJETIVO
Criar um site informativo e interativo que apresente a organização, seus projetos e suas formas de atuação. O site busca incentivar a participação da comunidade por meio de doações e voluntariado, além de aplicar conceitos de desenvolvimento web front-end.  

## TECNOLOGIAS UTILIZADAS
- HTML5: estrutura das páginas. 

- CSS3: aparência, organização visual e responsividade. 

- JavaScript: interações e funcionalidades das páginas. 

## COMO ABRIR O PROJETO

#### OPÇÃO 1
1. Clique em Code

2. Clique em Download Zip

3. Extraia o conteúdo do arquivo ZIP para uma pasta do computador. 

4. Abra a pasta "Site-Banco-de-Alimentos-main". 

5. Localize o arquivo `index.html`, dê dois cliques em `index.html` para abrir o site no navegador.

#### OPÇÃO 2
1. Clone este repositório:

   ```bash
   git clone https://github.com/EduardoCosta71/Site-Banco-de-Alimentos.git
   ```

2. Acesse a pasta do projeto.
3. Abra o projeto no Visual Studio Code.
4. Execute o arquivo `index.html` utilizando o navegador ou a extensão Live Server.


## Estrutura do site

O projeto é composto pelas seguintes páginas:

- **Início:** apresentação da organização e suas principais iniciativas.
- **A ONG:** informações institucionais e atuação social.
- **Projetos:** apresentação dos projetos e iniciativas da organização.
- **Doações:** informações e formulários para contribuições.
- **Voluntariado:** apresentação das oportunidades de participação.
- **Notícias:** divulgação de informações e conteúdos relacionados.
- **Galeria:** exposição de imagens.
- **Contato:** informações e formulário de comunicação.
- **Entrar:** página de acesso.

## Funcionalidades

- Navegação entre páginas independentes.
- Filtros de projetos por categoria.
- Formulários com validações e interações em JavaScript.
- Elementos interativos para melhorar a experiência do usuário.
- Layout responsivo para diferentes tamanhos de tela.
